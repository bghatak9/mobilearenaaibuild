# MobileArena

Enterprise-grade phone specification platform built with NestJS, Prisma, and PostgreSQL.

## Features

- Device management
- Brand management
- Category management
- Manufacturer management
- Bulk import support
- Swagger API documentation
- Prisma ORM
- PostgreSQL database
- JWT authentication (planned)
- Admin dashboard (planned)

## Tech Stack

- NestJS
- TypeScript
- Prisma
- PostgreSQL
- Swagger
- ESLint
- Prettier

## Installation

```bash
npm install
```

## Development

```bash
npm run start:dev
```

The API will be available at:

```
http://localhost:4000
```

Swagger documentation:

```
http://localhost:4000/api
```
